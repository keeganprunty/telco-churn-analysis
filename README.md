# telco-churn-analysis Overview
Predicting customer churn for a telecom company using logistic regression, random forest, and XGBoost. Includes EDA, feature engineering, model comparison, and business recommendations for retention strategy.

# Dataset
This dataset is called Telco Customer Churn. The data contains 7043 rows of customers with 21 features. Each row is a customer containing variables like gender, tenure, types of services, contracts, monthly charges etc. The dataset is from Kaggle as an IBM sample dataset.

[Data](https://www.kaggle.com/datasets/blastchar/telco-customer-churn/data)
